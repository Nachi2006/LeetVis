# LeetVis 

[**View Live App**](https://leetvis.nachi.systems)

LeetVis is a client-side visualizer for LeetCode-style data structure inputs. Ever struggled to mentally trace a tree from `[1,2,3,null,null,4,5]` or visualize an adjacency list? LeetVis solves that by generating instantly readable, interactive visual graphs right in your browser.

## Features

- **Binary Trees**: Paste standard level-order representations (`[1,2,3,null,null,4,5]`)
- **Graphs**: Support for adjacency lists (`[[1,2],[0,2],[0,1]]`) and edge lists
- **Linked Lists**: Visualize sequences (`[1,2,3,4,5]`)
- **Matrices / Grids**: Understand 2D arrays and island problems visually
- **Dual Themes**: Features a dark mode themed on winter and a light mode themed on summer
- **Export to PNG**: Download your visualizations to share with others or add to your notes.
- **Client-Side Only**: No backend required! Everything runs on Vite.

## Getting Started

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Nachi2006/LeetVis.git
   cd LeetVis
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
